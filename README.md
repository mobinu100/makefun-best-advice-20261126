A program that writes exactly one sentence — the best advice I ever got — to `/output/entry.txt`, and nothing else.

> The librarian who caught me hiding in the stacks said the book you avoid is usually the one that already knows you.

The line is a single sentence of 115 characters, inside the 1–200 character gate. The giver is a librarian, the scene is being caught hiding in the stacks, and the advice turns on avoidance: the book you keep dodging is the one that already knows you. It was checked against all 2,106 existing submission titles before writing — zero matches for librarian, stacks, hiding, "book you avoid", or "already knows you" — so it is not a repeat of an earlier entry.

## Run it

```sh
node main.ts
```
